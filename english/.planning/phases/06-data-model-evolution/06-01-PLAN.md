      ```sql

      SET "word_sense_id" = ws.id
      FROM "word_senses" ws
      WHERE sc."word_id" = ws."word_id"
        AND sc."card_type" = 'vocabulary';
      ```
   c. The DROP COLUMN statements for words.translation, words.familiarity, and srs_cards.word_id should come AFTER the data migration steps.

   IMPORTANT: drizzle-kit may generate the statements in a different order. Reorder so that:

   - ADD word_sense_id to srs_cards THIRD
   - UPDATE srs_cards (backfill) FOURTH
   - DROP old columns LAST

3. Run the migration:
   ```
   npx drizzle-kit migrate
   ```

