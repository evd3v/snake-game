    - POST /books/upload with non-EPUB file returns 400
    - GET /books returns array of { id, title, author, coverBase64, totalPages, createdAt }
    - DELETE /books/:id removes book and returns 204
    - DELETE /books/:id for non-existent book returns 404
    - After delete, GET /books no longer includes that book
    - Sentences stored in DB have correct pageNumber values (groups of ~6)
  </behavior>
  <action>
    1. Create `src/routes/books.ts` as FastifyPluginAsync (autoloaded, same pattern as sentences.ts):

       **POST /books/upload:**
       - `const file = await request.file()`
       - Validate file exists and mimetype is 'application/epub+zip' (return 400 via reply.badRequest if not)
       - Buffer the file: `const buffer = await file.toBuffer()`
       - Save to disk: uploadDir from `process.env.UPLOAD_DIR || './uploads'`, ensure dir exists with `fs.mkdir(recursive: true)`, write as `${Date.now()}-${file.filename}`
       - Call `parseEpub(filePath)` from services/epub-parser.ts
       - Inside a db.transaction: insert into books table, then for each chapter insert into bookChapters, then for each sentence insert into bookSentences with pre-computed pageNumber (PAGE_SIZE = 6, reset counter per chapter, merge final pages with < 3 sentences)
       - After all inserts, update books.totalPages
       - Return 201 with { id, title, totalPages }

       **GET /books:**
       - Select id, title, author, coverBase64, totalPages, createdAt from books, ordered by createdAt desc

       **DELETE /books/:id:**
       - Parse id from params
       - Select book filePath, return 404 if not found
       - Delete from books (CASCADE handles children)
       - Delete EPUB file from disk (catch errors silently)
       - Return 204
