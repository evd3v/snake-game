**1. Add types to web/src/types/api.ts:**

**2. Create web/src/stores/vocabulary.ts:**
Pinia store (composition API pattern like sentences.ts):
- State: items (VocabWord[]), total, page, limit (50), loading, filters (VocabFilters with search, familiarity, cefrLevel, cluster, srsState, sortBy, sortOrder), selectedWord (WordDetailResponse | null), detailLoading
- Actions:
  - fetchWords(): builds URLSearchParams from page + filters, calls apiGet('/vocabulary?...'), sets items + total
  - fetchWordDetail(wordId: number): calls apiGet('/vocabulary/:wordId'), sets selectedWord
  - markKnown(wordId: number): calls apiPost('/vocabulary/:wordId/mark-known'), refreshes the word in the list (re-fetch or optimistically update hasCard=false, srsState=null)
  - resetWord(wordId: number): calls apiPost('/vocabulary/:wordId/reset'), refreshes the word
  - setPage(n: number): sets page, calls fetchWords()
  - updateFilters(partial): merges into filters, resets page to 1, calls fetchWords()
  - clearFilters(): resets all filters, page=1, calls fetchWords()
- Debounce: search changes should NOT immediately trigger fetchWords -- the component handles debounce

**3. Create web/src/components/vocabulary/VocabularyFilters.vue:**
- Search input (text) with 300ms debounce -- emit search value to parent or call store.updateFilters

- SRS state select: All / New / Learning / Review / Not in review (none)
- Thematic cluster select: All + dynamically populate from current items or a separate fetch (simplest: extract unique clusters from loaded items -- acceptable for personal tool)
- Sort controls: sortBy (Alphabetical / Date added / CEFR level) + sortOrder toggle (asc/desc)
- Style: horizontal flex row wrapping on mobile, compact selects, consistent with project's design system (light borders, rounded, no framework)
