   - Import AnalysisModal and PageReport components
   - Add reactive state:
     ```typescript
     const analyzingId = ref<number | null>(null) // prevents double-tap
     const modalVisible = ref(false)
     const modalLoading = ref(false)
     const modalResult = ref<ReaderAnalysisResult | null>(null)
     const modalSentenceText = ref('')
     const pageStats = ref({ wordsLearned: 0, wordsKnown: 0, grammarPatternsFound: 0, collocationsLearned: 0 })

     ```
   - Modify `openSentence(id)` function:
     - Keep existing Set logic for gate tracking
     - Find the sentence in `pageData.value.sentences` by id
     - Set `modalSentenceText = sentence.text`
     - Set `analyzingId = id`, `modalVisible = true`, `modalLoading = true`
     - Call `apiPost('/books/sentences/${id}/analyze')`
     - If response.status === 'completed': set `modalResult = response.result`, `modalLoading = false`
     - If response.status === 'queued': poll `apiGet('/books/sentences/${id}/analyze/status/${response.jobId}')` every 1.5 seconds until completed or failed. On completed: set result. On failed: show error, close modal.
     - On error: set modalLoading = false, show error state in modal
     - Clear `analyzingId` when done (not on modal open -- only after API resolves)
     - If `analyzingId` is already set to this id, do nothing (prevent double-tap race condition)

   - Handle modal `learn` event:
     - Call `apiPost('/reader/${type}s/${id}/learn')` (pluralize type: words, collocations, grammar)
     - Increment `pageStats.value.wordsLearned` (or collocationsLearned) accordingly
     - Update local highlights: find the word in `pageData.value.sentences[].highlights` by matching lemma, change status to 'learning'

   - Handle modal `know` event:
     - Call `apiPost('/reader/${type}s/${id}/know')` (words, collocations, grammar)
     - Increment `pageStats.value.wordsKnown`
     - Update local highlights: find the word, change status to 'known' (remove highlight visually)

   - Handle modal `close` event:
     - Set `modalVisible = false`, `modalResult = null`, `analyzingId = null`
     - No full page re-fetch needed -- highlights already updated locally

   - Modify `goNext()`:
     - Before calling `loadPage(currentPage + 1)`:
       - If any stat > 0, set `showReport = true`
       - Wait for report to dismiss (or 3s auto-dismiss) before loading next page
       - On dismiss/timeout: reset `pageStats` to all zeros, `showReport = false`, then `loadPage()`
     - If all stats are 0, just load next page directly (no report)
