<task type="auto">
  <name>Task 2: Database schema and Drizzle migration</name>
  <files>src/db/schema/sentences.ts, src/db/schema/words.ts, src/db/schema/collocations.ts, src/db/schema/grammar-patterns.ts, src/db/schema/word-families.ts, src/db/schema/srs-cards.ts, src/db/schema/index.ts, src/db/relations.ts, src/db/index.ts, drizzle.config.ts</files>
  <action>
1. Create drizzle.config.ts per research: import dotenv/config, defineConfig with dialect postgresql, schema pointing to ./src/db/schema/index.ts, out ./drizzle, dbCredentials.url from DATABASE_URL env.

2. Create src/db/schema/sentences.ts:
   - Table `sentences` with: id (integer, PK, generatedAlwaysAsIdentity), text (text, notNull), translation (text, nullable), cefr_level (text, nullable), source_book (text, nullable), created_at (timestamp, defaultNow, notNull)

3. Create src/db/schema/words.ts:
   - pgEnum `familiarity` with values: never_seen, seen_unsure, understand_in_context
   - Table `words` with: id (integer, PK, generatedAlwaysAsIdentity), lemma (text, notNull, unique), translation (text, nullable), cefr_level (text, nullable), familiarity (familiarityEnum, default never_seen), thematic_cluster (text, nullable), created_at (timestamp, defaultNow, notNull)
   - Junction table `sentence_words` with: sentence_id (integer, notNull, references sentences.id), word_id (integer, notNull, references words.id), position (integer -- word position in sentence), primary key on (sentence_id, word_id)

4. Create src/db/schema/collocations.ts:
   - pgEnum `collocation_type` with values: collocation, phrasal_verb, idiom
   - Table `collocations` with: id (integer, PK, generatedAlwaysAsIdentity), text (text, notNull), translation (text, nullable), type (collocationTypeEnum, notNull), cefr_level (text, nullable), created_at (timestamp, defaultNow, notNull)
   - Junction table `sentence_collocations` with: sentence_id (integer, references sentences.id), collocation_id (integer, references collocations.id), primary key on both

5. Create src/db/schema/grammar-patterns.ts:
   - Table `grammar_patterns` with: id (integer, PK, generatedAlwaysAsIdentity), pattern (text, notNull, unique -- e.g. "would have + V3"), description (text, nullable), cefr_level (text, nullable), created_at (timestamp, defaultNow, notNull)
   - Junction table `sentence_grammar_patterns` with: sentence_id (integer, references sentences.id), grammar_pattern_id (integer, references grammarPatterns.id), primary key on both

6. Create src/db/schema/word-families.ts:
   - Table `word_families` with: id (integer, PK, generatedAlwaysAsIdentity), root_word (text, notNull), created_at (timestamp, defaultNow, notNull)
   - Add word_family_id (integer, nullable, references wordFamilies.id) to the words table. NOTE: Since words.ts is already created, add this column there. Use a forward-reference approach: define the column with a lazy reference or add it after wordFamilies is defined. Simplest: define wordFamilies first in this file and export it, then in words.ts import and reference it. OR define the FK in relations only. Best approach: add the column to words.ts as `wordFamilyId: integer('word_family_id')` without inline reference, and define the FK relationship in relations.ts.

7. Create src/db/schema/srs-cards.ts:
   - pgEnum `card_type` with values: vocabulary, grammar
   - pgEnum `card_state` with values: new, learning, review, relearning
   - Table `srs_cards` with: id (integer, PK, generatedAlwaysAsIdentity), card_type (cardTypeEnum, notNull), word_id (integer, nullable -- FK to words), grammar_pattern_id (integer, nullable -- FK to grammar_patterns), state (cardStateEnum, default new), due (timestamp, defaultNow, notNull), stability (real, default 0), difficulty (real, default 0), elapsed_days (integer, default 0), scheduled_days (integer, default 0), reps (integer, default 0), lapses (integer, default 0), last_review (timestamp, nullable), created_at (timestamp, defaultNow, notNull)

8. Create src/db/schema/index.ts: barrel file re-exporting all tables and enums from all schema files.

9. Create src/db/relations.ts: define Drizzle relations using the `relations()` helper from drizzle-orm:
   - sentences: many sentence_words, many sentence_collocations, many sentence_grammar_patterns
   - words: many sentence_words, one word_family (via word_family_id), many srs_cards
   - collocations: many sentence_collocations
   - grammarPatterns: many sentence_grammar_patterns, many srs_cards
   - wordFamilies: many words
   - srsCards: one word (nullable), one grammarPattern (nullable)
   - Junction tables: one sentence + one word/collocation/grammarPattern

10. Create src/db/index.ts: export createDb function that takes databaseUrl string and returns drizzle(url, { schema }). Export Database type.

11. Run `npx drizzle-kit generate` to produce the initial migration SQL. This requires DATABASE_URL but only for generation config -- it reads schema files. Set a dummy DATABASE_URL if needed: `DATABASE_URL=postgres://english:english@localhost:5432/english npx drizzle-kit generate`
  </action>

  </verify>
  <done>All 6 schema files + 3 junction tables defined, barrel export works, relations defined, drizzle.config.ts points to schema, migration SQL generated in drizzle/ directory</done>
