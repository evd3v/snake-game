<task type="auto">
  <name>Task 1: Install dependencies, create AI provider factory, Zod schema, prompts, and analyzeSentence</name>
  <files>package.json, .env.example, src/lib/ai/provider.ts, src/lib/ai/schemas.ts, src/lib/ai/prompts.ts, src/lib/ai/analyze-sentence.ts</files>
  <action>
1. Install dependencies:
   ```bash
   npm install ai @ai-sdk/openai @ai-sdk/anthropic zod wink-lemmatizer
   ```

2. Update `.env.example` to add:
   ```
   AI_PROVIDER=openai
   AI_MODEL=gpt-4o
   OPENAI_API_KEY=sk-your-key-here
   ANTHROPIC_API_KEY=sk-ant-your-key-here
   ```

3. Create `src/lib/ai/provider.ts`:
   - Export `getModel()` function that reads `AI_PROVIDER` env (default "openai") and `AI_MODEL` env
   - For "openai": return `openai(process.env.AI_MODEL ?? 'gpt-4o')`
   - For "anthropic": return `anthropic(process.env.AI_MODEL ?? 'claude-sonnet-4-20250514')`
   - Throw on unknown provider

4. Create `src/lib/ai/schemas.ts`:
   - Define `sentenceAnalysisSchema` as a Zod object with:
     - `translation: z.string()` (Russian translation)
     - `cefrLevel: z.enum(['A1','A2','B1','B2','C1','C2'])`
     - `vocabulary: z.array(...)` with fields: word, lemma, translation, partOfSpeech (enum: noun, verb, adjective, adverb, preposition, conjunction, pronoun, determiner, interjection), cefrLevel, thematicCluster
     - `collocations: z.array(...)` with fields: text, translation, type (collocation, phrasal_verb, idiom), cefrLevel
     - `grammarPatterns: z.array(...)` with fields: pattern, description, cefrLevel
     - `wordFamilies: z.array(...)` with fields: root, forms (string[])
   - Add `.describe()` on every field for AI guidance
   - Export the schema AND the inferred type `SentenceAnalysis`

5. Create `src/lib/ai/prompts.ts`:
   - Export `SYSTEM_PROMPT` constant: instruct AI as English language analysis expert helping Russian-speaking B1-B2 learner. Specify:
     - Translate to Russian
     - Extract ALL content words (skip articles, common pronouns)
     - Provide lemma (dictionary form) for each word
     - Identify collocations, phrasal verbs, idioms as separate units
     - Use grammar pattern notation: V1 (base), V2 (past), V3 (past participle), Ving, to-V, modal + V1
     - Group word families by shared root
     - Assign thematic cluster labels (emotions, business, nature, academic, daily_life, etc.)
   - Export `buildUserPrompt(sentence: string): string` that wraps the sentence in analysis request format

6. Create `src/lib/ai/analyze-sentence.ts`:
   - Import `generateText`, `Output` from 'ai'
   - Import `getModel` from './provider.ts'
   - Import `sentenceAnalysisSchema` from './schemas.ts'
   - Import `SYSTEM_PROMPT`, `buildUserPrompt` from './prompts.ts'
   - Export `async function analyzeSentence(sentence: string): Promise<SentenceAnalysis>`
   - Use `generateText({ model: getModel(), output: Output.object({ schema: sentenceAnalysisSchema }), system: SYSTEM_PROMPT, prompt: buildUserPrompt(sentence) })`
   - Return `output` (the parsed structured result)
   - Wrap in try/catch: on `NoObjectGeneratedError`, throw with descriptive message including the sentence

Use .ts import extensions everywhere (project convention from Phase 1).
  </action>

    <automated>npx tsc --noEmit</automated>
  </verify>
  <done>All 4 AI module files compile without errors. Provider factory, schema, prompts, and analyzeSentence function exported correctly.</done>
</task>
