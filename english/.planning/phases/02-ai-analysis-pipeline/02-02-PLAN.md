3. Create `src/services/word-family.ts`:
   - Export `async function linkWordFamilies(db: Database, wordFamilyGroups: { root: string; forms: string[] }[], insertedWords: Map<string, number>): Promise<void>`
   - For each word family group from AI:
     a. Check if any of the forms already exist in DB as words (query by lemma)
     b. If any existing word already has a `word_family_id`, use that family
     c. Otherwise, check if a `word_families` row with matching `rootWord` exists
     d. If no existing family found, create new `word_families` row with the root
     e. Update all words in the group (both existing DB words and newly inserted words from `insertedWords` map) to share the same `word_family_id`
   - Use Drizzle `eq()`, `inArray()` for queries
   - Import Database type from `../db/index.ts`

4. Create `src/services/analysis.ts`:
   - Import: Database, all schema tables, normalizeLemma, SentenceAnalysis type, linkWordFamilies
   - Export `async function storeAnalysisResults(db: Database, text: string, sourceBook: string | undefined, analysis: SentenceAnalysis): Promise<{ sentenceId: number; wordsInserted: number; collocationsInserted: number; grammarPatternsInserted: number }>`
   - Implementation steps:
     a. **Insert sentence**: Insert into `sentences` table with text, translation, cefrLevel, sourceBook. Get returned `sentenceId`.
     b. **Upsert words**: For each vocabulary item, normalize lemma via `normalizeLemma(analysis_item.lemma, analysis_item.partOfSpeech)`. Insert into `words` with `onConflictDoUpdate` on `lemma` target -- update `thematicCluster` (AI may provide better info on re-encounter). Collect a Map of lemma -> word.id for junction inserts.
     c. **Link sentence-words**: Insert into `sentenceWords` for each word, using position index.
     d. **Upsert collocations**: For each collocation, insert into `collocations` with `onConflictDoUpdate` on `text` target -- update translation if provided. Insert into `sentenceCollocations` junction.
     e. **Upsert grammar patterns**: For each grammar pattern, insert into `grammarPatterns` with `onConflictDoUpdate` on `pattern` target -- update description. Insert into `sentenceGrammarPatterns` junction.
     f. **Link word families**: Call `linkWordFamilies(db, analysis.wordFamilies, insertedWordsMap)`.
     g. Return summary object with counts.
   - Use `.returning()` on all inserts to get IDs for junction table inserts.
   - Handle potential duplicate junction table entries gracefully (use `onConflictDoNothing` on junction inserts since they have composite PKs).

Use .ts import extensions everywhere.
