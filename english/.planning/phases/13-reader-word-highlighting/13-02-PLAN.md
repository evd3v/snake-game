  <files>web/src/views/ReaderView.vue, web/src/router/index.ts, web/src/views/LibraryView.vue</files>
  <action>
    Create `web/src/views/ReaderView.vue` as a full-screen reading experience (no app header):

    **Script setup (Composition API, TypeScript):**
    - Route param: `bookId` from `/read/:bookId`
    - State: `currentPage` (number), `pageData` (PageResponse | null), `openedSentences` (Set<number>), `darkTheme` (boolean from localStorage key `reader-theme`), `loading` (boolean)
    - Computed: `allSentencesOpened` = openedSentences.size >= pageData.sentences.length
    - `loadPage(page)`: call `apiGet(`/books/${bookId}/page/${page}`)`, set pageData, clear openedSentences, save position via `apiPatch(`/books/${bookId}/position`, { pageNumber: page })`
    - `openSentence(id)`: add to openedSentences set (Phase 14 will add modal here)
    - `goNext()`: if allSentencesOpened and currentPage < totalPages-1, loadPage(currentPage+1)
    - `goPrev()`: if currentPage > 0, loadPage(currentPage-1)
    - `toggleTheme()`: flip darkTheme, save to localStorage
    - `onMounted`: load page at savedPosition (fetch `/books/${bookId}/page/0` first to get savedPosition, then load that page; or just load page 0 and if savedPosition differs, load savedPosition)

    **Template structure:**
    ```
    <div class="reader" :class="{ dark: darkTheme }">
      <header class="reader-header">
        <router-link to="/library" class="back-btn">Back</router-link>
        <span class="page-indicator">Page {{ currentPage + 1 }} / {{ pageData.totalPages }}</span>
        <button @click="toggleTheme" class="theme-btn">{{ darkTheme ? 'Light' : 'Dark' }}</button>
      </header>

      <main class="reader-content">
        <div v-for="sentence in pageData.sentences" :key="sentence.id"
             class="sentence" :class="{ opened: openedSentences.has(sentence.id) }"
             @click="openSentence(sentence.id)">
          <span v-for="(token, i) in sentence.highlights" :key="i"
                :class="highlightClass(token.status)">{{ token.word }}</span>
        </div>
      </main>

      <footer class="reader-nav">
        <button @click="goPrev" :disabled="currentPage === 0" class="nav-btn">Previous</button>
        <button @click="goNext" :disabled="!allSentencesOpened || currentPage >= pageData.totalPages - 1"
                class="nav-btn nav-btn-primary">Next</button>
      </footer>
    </div>
    ```

    **highlightClass(status)** helper: returns `'word-new'` for 'new', `'word-learning'` for 'learning', `''` for 'known' or null.

    **Scoped CSS with CSS custom properties for theming:**
    - Light theme (default): white bg, dark text, blue-100 for new, amber-100 for learning
    - Dark theme (.dark class): dark navy bg (#1a1a2e), light text, darker blue/amber highlights
    - Full viewport height, flex column layout (header, scrollable content, fixed footer)
    - Sentences: readable font size (18px), line-height 1.8, cursor pointer, padding
    - Opened sentences: subtle left border or background change to show they've been clicked
    - Navigation footer: fixed at bottom, flex row with prev/next buttons
    - Disabled next button: reduced opacity, not-allowed cursor
    - Responsive: comfortable on mobile (padding adjustments)

    **Add route** in `web/src/router/index.ts`:
    ```typescript
    {
      path: '/read/:bookId',
      name: 'reader',
      component: () => import('../views/ReaderView.vue'),
    }
    ```
