<task type="auto" tdd="true">
  <name>Task 1: Word highlighter service with unit tests</name>
  <files>src/services/word-highlighter.ts, tests/word-highlighter.test.ts</files>
  <behavior>
    - tokenize("Hello, world!") produces tokens with correct offsets and isWord flags
    - Punctuation-attached words ("Hello,") are cleaned to "hello" for lookup
    - Contractions ("don't") are handled (treated as word tokens)
    - Words found in vocabulary with familiarity=never_seen return status "new"
    - Words with active SRS card (state=new/learning/relearning) return status "learning"
    - Words with all senses known (no never_seen, no active SRS) return status "known"
    - Words NOT in vocabulary at all return status null (no highlight)
    - Multiple POS lemmatizations are tried (noun, verb, adjective) to find a match
    - Batch query: all unique tokens from all sentences queried in ONE db call
  </behavior>
  <action>
    Create `src/services/word-highlighter.ts` following the research code example closely:

    1. `tokenize(text)` function: regex `(\w+(?:'\w+)?)|([^\w]+)` to split into word/non-word tokens with offsets.
    2. `cleanToken(token)` function: strip non-word chars, lowercase.
    3. `highlightSentences(db, sentences)` async function:
       - Tokenize all sentences, collect unique clean words
       - For each clean word, generate possible lemmas using `normalizeLemma` from `src/lib/lemmatizer.ts` for noun/verb/adjective, plus raw lowercase
       - Batch query: `SELECT words.lemma, word_senses.familiarity, srs_cards.state FROM words INNER JOIN word_senses LEFT JOIN srs_cards WHERE words.lemma IN (...possibleLemmas)`
       - Build lemmaStatus map with priority: new > learning > known
       - Map tokens back to highlights with status from lemmaStatus (try all POS lemmas, pick first match)
       - Return `Map<sentenceId, TokenHighlight[]>`

    Type for export:
    ```typescript
    interface TokenHighlight {
      word: string;
      offset: number;
      length: number;
      status: 'new' | 'learning' | 'known' | null;
    }
    ```

    Write tests in `tests/word-highlighter.test.ts`:
    - Use real DB (same pattern as books-api.test.ts with buildTestApp)
    - Insert test words/senses/cards in beforeAll
    - Test: sentence with known word -> status "known"
    - Test: sentence with never_seen word -> status "new"
    - Test: sentence with learning SRS card -> status "learning"
    - Test: sentence with word not in DB -> status null
    - Test: punctuation tokens get status null
    - Test: multiple sentences batched in one call
  </action>
