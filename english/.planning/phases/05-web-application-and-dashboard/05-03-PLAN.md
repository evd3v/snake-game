  <files>web/src/stores/sentences.ts, web/src/api/client.ts, web/src/components/sentence/SentenceForm.vue, web/src/components/sentence/AnalysisResult.vue, web/src/components/sentence/WordSelector.vue, web/src/views/SentenceInputView.vue</files>
  <action>
  1. **Add `apiPatch` to `web/src/api/client.ts`**: The existing client has `apiGet` and `apiPost`. Add `apiPatch<T>(path: string, body: unknown): Promise<T>` with method `'PATCH'`. Needed for familiarity updates.

  2. **web/src/stores/sentences.ts**: Pinia store using Composition API:
     - State: `text` (string), `loading` (boolean), `polling` (boolean), `error` (string | null), `result` (analysis result | null), `words` (word array), `sentenceId` (number | null)
     - Action `analyze(text: string)`:
       - POST `/sentences` with { text }, get jobId
       - Set `polling = true`
       - Poll GET `/sentences/${jobId}/status` every 1.5 seconds
       - On `completed`: set `result`, extract `sentenceId` from result, fetch words via GET `/sentences/${sentenceId}/words`, set `polling = false`
       - On `failed`: set error, set `polling = false`
       - Use AbortController pattern: store an abort signal, cancel polling on new submission or component unmount
     - Action `setFamiliarity(wordId: number, familiarity: string)`:
       - PATCH `/words/${wordId}/familiarity` with { familiarity }
       - Update the word in local `words` array
     - Action `createSrsCard(wordId: number)`:
       - POST `/words/${wordId}/srs-card`
     - Action `reset()`: clear all state for new submission

  3. **SentenceForm.vue**:
     - `<textarea>` for sentence input (placeholder: "Enter an English sentence from your book...")
     - Submit button (disabled when empty or loading)
     - Emits `submit(text: string)` event
     - Shows character count
     - Clean styling: bordered textarea, prominent submit button

  4. **AnalysisResult.vue**:
     - Props: `result` (the analysis object from job completion)
     - Displays:
       - Translation in a highlighted box
       - CEFR level badge (e.g., "B2" in a colored pill)
       - Grammar patterns list (pattern + description for each)
       - Collocations if present
     - Collapsible sections for grammar and collocations (use details/summary HTML elements for simplicity)

  5. **WordSelector.vue**:
     - Props: `words` (array from GET /sentences/:id/words)
     - Emits: `set-familiarity(wordId, familiarity)`, `create-card(wordId)`
     - Render each word as a card/row showing: lemma, translation, CEFR level, thematic cluster
     - For each word, show three familiarity buttons: "Never seen" / "Seen but unsure" / "Understand in context"
     - Active familiarity button highlighted
     - "Add to review" button that creates an SRS card (POST /words/:wordId/srs-card)
     - Show confirmation after card creation (e.g., checkmark replaces button)

  6. **SentenceInputView.vue**:
     - Uses `useSentenceStore`
     - Top: SentenceForm, calls `store.analyze(text)` on submit
     - While polling: show animated loading indicator with "Analyzing..." text
     - After analysis: show AnalysisResult (translation, grammar, collocations)
     - Below result: show WordSelector with extracted words
     - Wire up familiarity and SRS card actions through the store
     - "New sentence" button to reset and start over

  Use `<script setup lang="ts">` and scoped CSS for all components. Keep styles consistent with dashboard (same border-radius, colors, spacing).
