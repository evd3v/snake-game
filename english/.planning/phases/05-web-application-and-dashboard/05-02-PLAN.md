     - State refs: `stats` (ProgressStats | null), `weakSpots` (WeakSpot[]), `activity` (DayActivity[]), `clusters` (ClusterStats[]), `loading` (boolean), `error` (string | null)
     - Action `fetchAll()`: calls all four endpoints in parallel with `Promise.all`, sets loading/error appropriately
     - Uses `apiGet` from `@/api/client`

  2. **ProgressCounters.vue** (DASH-01):
     - Props: `stats: ProgressStats`
     - Two card groups (Words and Grammar), each showing three counters: New (blue), Learning (amber), Known (green)
     - Each counter shows the count and a label
     - Show total at the bottom of each group
     - Use scoped CSS with clean card styling (border, border-radius, padding)

  3. **WeakSpots.vue** (DASH-02):
     - Props: `spots: WeakSpot[]`
     - Render a list/table of weak spots
     - Each row shows: name (+ translation for words, + description for grammar), type badge (vocabulary/grammar), fail rate as percentage, total reviews count
     - Sort by failRate DESC (API already does this)
     - Show "No weak spots yet" when array is empty
     - Color-code fail rates: >70% red, >40% amber, else green

  4. **ActivityHeatmap.vue** (DASH-03):
     - Props: `data: DayActivity[]`
     - Custom SVG heatmap (NOT vue3-calendar-heatmap -- it is stale per research)
     - Generate a grid of 52 columns (weeks) x 7 rows (days) for the last 365 days
     - Each cell colored by activity intensity (reviews + additions count): 0=#ebedf0, low=#9be9a8, mid=#40c463, high=#30a14e, max=#216e39
     - Show month labels along the top
     - Show day labels (Mon, Wed, Fri) along the left
     - Tooltip on hover showing date and counts (use title SVG element for native tooltip)
     - Calculate and display current streak (consecutive days with activity) above the heatmap

  5. **ClusterCoverage.vue** (DASH-04):
     - Props: `clusters: ClusterStats[]`
     - Render each cluster as a horizontal stacked bar showing new/learning/known proportions
     - Cluster name on the left, bar in the middle, total count on the right
     - Color segments: new=blue, learning=amber, known=green (consistent with ProgressCounters)
     - Show "No vocabulary clusters yet" when array is empty
     - Use CSS for stacked bars (flexbox with percentage widths), no charting library needed

  Use Vue 3 `<script setup lang="ts">` and scoped CSS for all components. Keep styles clean and minimal -- plain CSS, no utility framework.
