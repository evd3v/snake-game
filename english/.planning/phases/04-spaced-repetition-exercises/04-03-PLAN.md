  <action>
    1. Add to `src/bot/services/api-client.ts`:
       - `getDueCards(limit?: number)`: GET /review/due?limit=N, returns array of due card objects
       - `rateCard(cardId: number, rating: number)`: POST /review/:cardId/rate with { rating }, returns { success, nextDue }

    2. Create `src/bot/keyboards/review.ts`:
       - `buildRevealKeyboard(cardId: number)`: Returns InlineKeyboard with single "Show answer" button, callback data `rv:{cardId}`
       - `buildRatingKeyboard(cardId: number)`: Returns InlineKeyboard with 4 buttons in a row: Again (`rt:{cardId}:1`), Hard (`rt:{cardId}:2`), Good (`rt:{cardId}:3`), Easy (`rt:{cardId}:4`)
       - `buildEndSessionKeyboard()`: Returns InlineKeyboard with "End session" button, callback data `rs`

    3. Create `src/bot/handlers/review.ts`:
       - Define ReviewSession interface: { cards: DueCard[], currentIndex: number, revealed: boolean, stats: { total: number, ratings: Record<number, number> } }
       - Module-level `reviewSessions = new Map<number, ReviewSession>()` keyed by chatId
       - Export `registerReviewHandlers(bot: Bot)`:

       **bot.command('review'):**
       - Check if session already active for chatId -> reply "You have an active review session" with end session keyboard
       - Call apiClient.getDueCards(20)
       - If empty -> reply "No cards due for review! Come back later."
       - Create session in map
       - Call showCard(ctx, cards[0]) to display first card

       **showCard(ctx, card) helper:**
       - For vocabulary: `<b>{lemma}</b> ({cefrLevel})\n\n<i>"{sentenceText}"</i>` with reveal keyboard
       - For grammar: `Fill in the blank:\n\n{exercise.sentence}` with reveal keyboard. If no exercise available, show pattern name with "No exercises available" note
       - Use HTML parse_mode

       **bot.callbackQuery(/^rv:(\d+)$/) -- reveal:**
       - Get session, validate not stale
       - Set session.revealed = true
       - For vocabulary: edit message to add `\n\nTranslation: <b>{translation}</b>` + rating keyboard
       - For grammar: edit message to add `\n\nAnswer: <b>{exercise.answer}</b>` (+ hint if present) + rating keyboard

       **bot.callbackQuery(/^rt:(\d+):([1-4])$/) -- rate:**
       - Get session, validate
       - Call apiClient.rateCard(cardId, rating)
       - Update stats (increment ratings[rating], total)
       - Advance currentIndex
       - If more cards: show next card
       - If no more: show session summary and clean up session
       - Summary format: "Review complete! {total} cards reviewed.\nAgain: {n} | Hard: {n} | Good: {n} | Easy: {n}"

       **bot.callbackQuery('rs') -- end session:**
       - Show partial summary if any cards were reviewed, else "Session ended"
       - Clean up session from map

    4. Update `src/bot/index.ts`:
       - Import registerReviewHandlers from './handlers/review.ts'
       - Call registerReviewHandlers(bot) BEFORE bot.on('message:text', ...) so /review command is not caught by the text handler

       - Test rate callback advances to next card
