  <name>Task 1: Word API routes (GET sentence words, PATCH familiarity)</name>
  <files>src/routes/words.ts, tests/words-api.test.ts</files>
  <behavior>
    - GET /sentences/:sentenceId/words returns array of { id, lemma, translation, cefrLevel, familiarity, thematicCluster } for words linked via sentenceWords junction
    - GET /sentences/999/words returns empty array (not 404) for non-existent sentence
    - PATCH /words/:id/familiarity with body { familiarity: "seen_unsure" } updates the word and returns updated word
    - PATCH /words/999/familiarity returns 404 for non-existent word
    - PATCH /words/:id/familiarity with invalid familiarity value returns 400
  </behavior>
  <action>
    Create `src/routes/words.ts` as a Fastify route plugin (plain export, NOT fp()-wrapped -- follows established route pattern from sentences.ts).

    **GET /sentences/:sentenceId/words:**
    - Join `sentenceWords` with `words` on wordId where sentenceId matches param
    - Use Drizzle `db.select().from(words).innerJoin(sentenceWords, eq(words.id, sentenceWords.wordId)).where(eq(sentenceWords.sentenceId, param))`
    - Return array of word objects ordered by position
    - Return empty array if sentence doesn't exist

    **PATCH /words/:id/familiarity:**
    - Accept body `{ familiarity: 'never_seen' | 'seen_unsure' | 'understand_in_context' }`
    - Fastify JSON schema validation: body requires `familiarity` field, enum of three values
    - Use `db.update(words).set({ familiarity }).where(eq(words.id, param)).returning()`
    - Return 404 if no rows returned (word doesn't exist)
    - Return updated word object

    Create `tests/words-api.test.ts` using buildTestApp/cleanupTestApp pattern from `tests/helpers/setup.ts`. Insert seed data (a sentence + words + sentenceWords) in beforeEach, clean up in afterEach. Test all 5 behaviors listed above.
  </action>

  </verify>
