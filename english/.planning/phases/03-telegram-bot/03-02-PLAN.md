    - buildWordSelectionKeyboard returns InlineKeyboard with one row per word showing "lemma -- translation [CEFR]", plus "Save N word(s)" button when selection non-empty
    - buildWordSelectionKeyboard marks selected words with a checkmark prefix
    - buildFamiliarityKeyboard returns 4 buttons: "Never seen", "Seen but unsure", "Understand in context", "Skip"
    - Callback data stays under 64 bytes for all cases
    - sel: callback toggles word in selection set, re-renders keyboard
    - done: callback triggers familiarity flow for first selected word
    - fam: callback saves familiarity via API, advances to next word or shows completion
  </behavior>
  <action>
    **Create src/bot/keyboards/analysis.ts:**
    - `buildWordSelectionKeyboard(sentenceId: number, words: WordInfo[], selected: Set<number>): InlineKeyboard`
      - One row per word: checkmark prefix if selected, label = `{mark} {lemma} -- {translation} [{cefrLevel}]`
      - Callback data: `sel:{sentenceId}:{wordId}` (numeric IDs keep it under 64 bytes)
      - If selected.size > 0, add a final row: `Save {N} word(s)` with callback `done:{sentenceId}`
    - `buildFamiliarityKeyboard(sentenceId: number, wordId: number): InlineKeyboard`
      - 3 rows + skip: "Never seen" (`fam:{sId}:{wId}:ns`), "Seen but unsure" (`fam:{sId}:{wId}:su`), "Understand in context" (`fam:{sId}:{wId}:uc`), "Skip" (`fam:{sId}:{wId}:skip`)

    **Create src/bot/handlers/vocabulary.ts:**
    - Maintain in-memory state: `Map<string, { selected: Set<number>, words: WordInfo[], pendingFamiliarity: number[] }>` keyed by `chatId:sentenceId`
    - Export `initSelection(chatId: number, sentenceId: number, words: WordInfo[])` -- called from sentence handler after displaying results
    - Export `registerVocabularyHandlers(bot: Bot, apiClient: ApiClient)` which registers:
      - `bot.callbackQuery(/^sel:(\d+):(\d+)$/, handler)` -- toggle wordId in selected set, call `ctx.editMessageReplyMarkup` with updated keyboard, call `ctx.answerCallbackQuery()`
      - `bot.callbackQuery(/^done:(\d+)$/, handler)` -- get selected word IDs, set as pendingFamiliarity list, edit message to show first word's familiarity prompt using `buildFamiliarityKeyboard`, `ctx.answerCallbackQuery()`
      - `bot.callbackQuery(/^fam:(\d+):(\d+):(.+)$/, handler)` -- if not "skip", call `apiClient.setFamiliarity(wordId, FAMILIARITY_MAP[code])`. Remove word from pending list. If more words pending, edit message for next word. If done, edit message with "Saved {N} words to vocabulary!" confirmation and clean up state. Always `ctx.answerCallbackQuery()`.
    - Handle stale callbacks gracefully: if state not found for chatId:sentenceId, answer with "This selection has expired" and return

    **Update src/bot/handlers/sentence.ts:**
    - After formatting analysis result and getting words, call `initSelection(chatId, sentenceId, words)`
    - Attach `buildWordSelectionKeyboard(sentenceId, words, new Set())` as reply_markup when editing the processing message with results

    **Update src/bot/index.ts:**
    - Import and call `registerVocabularyHandlers(bot, apiClient)` before `bot.start()`

    **Create tests/bot-vocabulary.test.ts:**
    - Test `buildWordSelectionKeyboard`: returns correct number of rows, selected words have checkmark, "Save" button appears when selection non-empty, callback data format is correct
    - Test `buildFamiliarityKeyboard`: returns 4 buttons with correct callback data format
    - Test callback data stays under 64 bytes with sentenceId=99999 and wordId=99999
    - Test FAMILIARITY_MAP maps all short codes correctly
  </action>
