       ```typescript
       // Review types
       export interface DueCard {
         cardId: number
         cardType: 'vocabulary' | 'grammar'
         state: string
         due: string
         word?: {
           lemma: string
           translation: string | null
           cefrLevel: string | null
           partOfSpeech: string | null
         }
         sentence?: string
         pattern?: { pattern: string; description: string }
         exercise?: {
           id: number
           sentence: string
           answer: string
           hint: string | null
           difficultyLevel: number
         }
       }

       export interface ReviewStats {
         total: number
         ratings: Record<1 | 2 | 3 | 4, number>
       }
       ```

    2. Create web/src/stores/review.ts following the vocabulary store pattern (composition API):
       - State refs: cards (DueCard[]), currentIndex (number), revealed (boolean), loading (boolean), sessionActive (boolean), error (string|null), fetchedAt (string - ISO timestamp of when cards were fetched)
       - Stats: reactive ReviewStats { total: 0, ratings: { 1: 0, 2: 0, 3: 0, 4: 0 } }
       - Computed: currentCard (cards[currentIndex] or null), progress (currentIndex / cards.length, 0 if empty), isComplete (sessionActive && currentIndex >= cards.length)
       - Actions:
         a. startSession(): set loading=true, fetch apiGet<DueCard[]>('/review/due?limit=20'), store fetchedAt = new Date().toISOString(), set cards, reset currentIndex=0, revealed=false, stats, sessionActive=true, loading=false. If cards.length === 0, set sessionActive=false (no cards due).
         b. reveal(): set revealed=true
         c. rate(rating: 1|2|3|4): call apiPost('/review/${currentCard.cardId}/rate', { rating, fetchedAt }). On 409, skip card (increment index, don't count in stats). On success, increment stats.ratings[rating] and stats.total, increment currentIndex, set revealed=false. Wrap in try/catch -- on 409 just skip, on other errors set error.
         d. endSession(): set sessionActive=false
       - Return all state, computed, and actions

    3. Add /review route to web/src/router/index.ts:
       Add route object: { path: '/review', name: 'review', component: () => import('../views/ReviewView.vue') }
       Place it after the /vocabulary route.
