    **ReviewProgress.vue** — Simple progress bar component:
    - Props: progress (number 0-1), current (number), total (number)
    - Template: container div with inner div whose width is `${progress * 100}%`. Show "{current} / {total}" text.
    - Style: height 8px, bg #e2e8f0, fill #2563eb, rounded, smooth width transition (0.3s ease)

    **RatingButtons.vue** — Four rating buttons:
    - Props: disabled (boolean, default false)
    - Emits: rate(rating: number)
    - Template: Four buttons in a row: Again (1), Hard (2), Good (3), Easy (4). Each shows the label and keyboard shortcut hint (e.g. "Again [1]").
    - Style: Grid of 4 buttons. Again = red (#ef4444), Hard = orange (#f97316), Good = green (#22c55e), Easy = blue (#2563eb). White text, rounded, padding 12px 16px, font-weight 600. Hover: darken slightly. Disabled: opacity 0.5, pointer-events none.

    **ReviewCard.vue** — Card display with front/back states:
    - Props: card (DueCard), revealed (boolean)
    - Template:
      - Vocabulary card (card.cardType === 'vocabulary'):
        - Front: lemma large (24px bold), POS tag if present (small badge), CEFR badge if present (colored by level), context sentence in italics (the card.sentence field)
        - Back (v-if="revealed"): translation below a divider line. If no translation, show "---"
        - Hint text when not revealed: "Press Space or Enter to reveal"
      - Grammar card (card.cardType === 'grammar'):
        - If card.exercise exists:
          - Front: exercise.sentence displayed with the blank clearly visible (style the blank/gap)
          - If exercise.hint, show hint in muted text
          - Back (v-if="revealed"): exercise.answer in bold green
        - If no exercise (exhausted):
          - Show card.pattern?.pattern as title, "No exercises available -- rate based on your knowledge of this pattern" as message
          - Treat as already revealed (always show rating buttons)
    - Style: Card container with white bg, rounded-lg, shadow, padding 32px, max-width 600px, centered. Vocab lemma large and bold. Grammar cloze sentence with 18px font.

    **ReviewSummary.vue** — End-of-session stats:
    - Props: stats (ReviewStats)
    - Emits: restart, goHome
    - Template: "Session Complete" heading. Show total cards reviewed. Show breakdown: Again/Hard/Good/Easy counts each on its own row with colored indicator matching RatingButtons colors. Two action buttons: "Review Again" (emits restart) and "Back to Dashboard" (emits goHome).
    - Style: Card container similar to ReviewCard. Stats in a clean grid/list. Buttons styled like RatingButtons but neutral colors.

    **ReviewView.vue** — Session orchestrator:
    - Uses useReviewStore()
    - On mounted: call store.startSession(). Add window keydown listener. On unmounted: remove listener, call store.endSession() if session was active.
    - Keyboard handler (handleKeydown):
      - Guard: if document.activeElement is input/textarea/select, return (defensive)
      - If not revealed: Space or Enter calls store.reveal()
      - If revealed: keys 1-4 call store.rate(Number(e.key) as 1|2|3|4)
    - Template states:
      - loading: Show "Loading review cards..." spinner/text
      - error: Show error message with "Try Again" button
      - !sessionActive && cards.length === 0: "No cards due for review. Come back later!" with link to dashboard
      - isComplete: Show ReviewSummary with stats. "Review Again" calls startSession(), "Back to Dashboard" navigates to /
      - default (active session): Show ReviewProgress at top, ReviewCard in center, RatingButtons below card (visible only when revealed). If card has no exercise (grammar exhausted), show RatingButtons immediately.
    - Style: Centered layout, max-width 640px, margin auto, padding 24px. Review area takes full viewport height minus header.

    **App.vue** — Add Review nav link:
    - Add a RouterLink to /review with text "Review" in the nav section, after Vocabulary link.
    - Follow exact same pattern as existing nav links (.nav-link class, :class active check on route.path).
