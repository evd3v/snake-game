# English Learning App

## What This Is

Персональное приложение для изучения английского через чтение книг. EPUB-читалка в браузере с AI-анализом каждого предложения — LingQ-подобный подход с глубоким разбором грамматики, коллокаций и лексики. Telegram-бот остаётся для произвольных предложений вне книг. Интервальное повторение с адаптивной прогрессией от простого к сложному.

## Core Value

Пользователь читает реальную книгу в EPUB-читалке, получает AI-разбор каждого предложения (перевод, грамматика, лексика, коллокации), а извлечённые единицы попадают в систему интервального повторения — обучение через чтение в контексте.

### Active

## Current Milestone: v2.0 EPUB Reader & LingQ-style Learning

**Goal:** Перейти от ручного ввода предложений к чтению книг в EPUB-читалке с обязательным разбором каждого предложения, подсветкой слов по статусу и LingQ-подобным flow обучения.

**Target features:**
- Загрузка и парсинг EPUB книг
- Мобильная читалка в браузере (перелистывание, позиция, ночная тема)
- Страницы по 5-7 предложений с обязательным прокликиванием каждого
- AI-анализ предложений с модалкой (перевод, слова, коллокации, грамматика)
- Кэширование анализа — повторный запрос не нужен
- В модалке: только новые слова/коллокации с кнопками "учить" / "знаю"
- Подсветка слов в тексте по статусу (новое/учу/знаю)
- Мини-отчёт при перелистывании страницы
- Убрать фильтрацию A1/A2 — все слова добавляются, пользователь решает сам

### Out of Scope

- Мобильное нативное приложение — веб + бот достаточно
- Социальные функции — личный инструмент
- Аудио/произношение — фокус на чтении и грамматике
- Оглавление / навигация по книге — на старте не нужно
- Подсветка прогресса per-book (% прочитано) — усложняет, не приоритет

## Context

Цель пользователя — выйти на уровень C1 в чтении: свободно читать художественную и нехудожественную литературу без переводчика. Текущий уровень предположительно B1-B2. Основной метод — extensive reading с систематическим сбором и повторением встреченного материала.

Ключевое отличие от существующих инструментов (Anki, LingQ): не просто карточки со словами, а связная система, которая видит грамматические паттерны, коллокации, word families и отслеживает прогрессию по ним.

## Constraints

- **Tech stack**: Vue 3 + TypeScript (фронтенд), бэкенд на усмотрение (Node.js / Python), PostgreSQL
- **AI**: Claude API или OpenAI API — без привязки к конкретному провайдеру
- **Deploy**: VPS + Docker Compose
- **Пользователь**: один (автор), авторизация не критична на первом этапе
- **Бюджет AI**: личный, разумное потребление токенов (батч-генерация упражнений)

## Key Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| Два входа (бот + веб) вместо одного | Бот для быстрого ввода при чтении, веб для осознанной работы | ✓ Phase 3+5 |
| Леммы + коллокации вместо просто слов | C1 требует знания сочетаний, не изолированных слов | ✓ Phase 2 |
| Паттерн-трекинг вместо абстрактных категорий | Конкретные паттерны (would have + V3) полезнее чем "Third Conditional" | ✓ Phase 2 |
| FSRS вместо SM-2 | Более современный алгоритм с лучшей адаптацией к пользователю (ts-fsrs) | ✓ Phase 4 |
| Батч-генерация упражнений | Не ждать ИИ при каждом повторении, экономия токенов и времени | ✓ Phase 4 |
| EPUB-читалка вместо ручного ввода | LingQ доказал: чтение в контексте эффективнее изолированного ввода | — Pending |
| Предложение как единица анализа | POS, коллокации, грамматика определяются только в контексте предложения | — Pending |
| Убрать A1/A2 фильтрацию | Пользователь сам решает что учить через "учить"/"знаю" | — Pending |
